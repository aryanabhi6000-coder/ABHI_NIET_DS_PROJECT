Student Admission Record Management System

A Windows XP styled GUI application for managing university student records.

## Features

- Unique ID generation for each student
- Student name and teacher's remarks
- Marks management by semester and subject
- Document attachment
- Add, delete, and view student records

## Building

Run `build.bat` to compile the application.

## Usage

1. Run `student_management.exe`
2. Enter student name and remark, click "Add Student"
3. Select a student from the list
4. Add subjects, set marks, add documents
5. View detailed information

## Files

- main.c: Main application entry
- student.c/h: Student data structures
- hashmap.c/h: ID management
- gui.c/h: GUI components
